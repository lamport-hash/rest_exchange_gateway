Error codes

HTTPcodemeaning
400invalid_requestschema/field validation (unknown fields are named)
400risk_max_qty / risk_max_notional / risk_max_position / risk_invalid_valuepre-trade risk rejection — reason carries the limit
404not_foundunknown clientOrderId (incl. venue “does not exist”)
409order_terminalcancel/amend on a filled/canceled/rejected order
409venue_rejectedvenue rejected the request (reason carries the venue code)
502venue_unavailabletransport failure, outcome unknown or unresolved
500persistence / internallocal failure after venue acceptance / bug

Order state machine

illegal transitions are discarded, never errors — one rule arbitrates duplicates, out-of-order WS and REST-vs-WS races 
stateDiagram-v2
    [*] --> Live : venue ack
    [*] --> Rejected : risk / venue rejection
    Live --> PartiallyFilled : partial fill
    Live --> Filled : full fill
    Live --> Canceled : cancel ack
    Live --> Rejected : reconcile - venue absent
    PartiallyFilled --> PartiallyFilled : more fills (monotonic)
    PartiallyFilled --> Filled : full fill
    PartiallyFilled --> Canceled : cancel ack
    Filled --> [*]
    Canceled --> [*]
    Rejected --> [*]

Place: idempotency and unknown-outcome resolution

three layers — registry replay, state-machine arbitration, adapter resolve-then-retry 
sequenceDiagram
    participant C as Client
    participant R as REST layer
    participant O as OMS registry
    participant A as Venue adapter
    participant V as Exchange

    C->>R: POST /orders {clientOrderId, …}
    R->>O: place(request)
    alt clientOrderId already known
        O-->>C: recorded outcome, replayed=true (no venue call)
    else new order
        O->>O: pre-trade risk checks
        alt rejected
            O-->>C: 400 risk_*
        else pass
            O->>A: place (venue I/O outside registry lock)
            A->>V: place order
            alt ack received
                A-->>O: exchangeOrderId
                O->>O: append event log
                O-->>C: 201 live
            else transport failure (outcome unknown)
                A->>V: lookup by clientOrderId
                alt found
                    A-->>O: synthesized ack
                    O-->>C: 201 live
                else conclusively absent
                    A->>V: re-send identical order
                else unresolved
                    O-->>C: 502 venue_unavailable (nothing recorded — client may retry)
                end
            end
        end
    end

Restart recovery

replay → reconnect feeds → reconcile; reconcile also runs on every WS reconnect 
sequenceDiagram
    participant G as Gateway startup
    participant L as Event log (JSONL)
    participant O as OMS
    participant V as Venues

    G->>L: replay (torn tail truncated)
    G->>O: rebuild registry
    G->>V: connect feeds (WS login/subscribe)
    G->>O: reconcile()
    O->>V: get_open_orders per venue
    O->>O: adopt venue-live unknown orders
    O->>O: refresh fills, resolve non-terminal
    O->>O: venue-absent -> Rejected / unreachable -> kept, warned
    G->>G: serve REST, reconcile again on every WS reconnect
